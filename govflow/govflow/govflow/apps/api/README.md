# GovFlow AI — Backend API

FastAPI backend foundation for GovFlow AI (Track A — Phase 0).

## Stack

- Python 3.12+
- FastAPI (async)
- Pydantic v2 / pydantic-settings for configuration
- SQLAlchemy 2.0 (async) + asyncpg against PostgreSQL
- Alembic for migrations
- Redis abstraction (`app/core/redis.py`) based on `redis.asyncio`
- structlog for structured logging
- pytest, Ruff, mypy

This phase intentionally implements **no** AI, browser automation, OCR, or
government service integrations — the structure is in place for later phases.

## Quick start

```bash
# From this directory (apps/api):
make install          # creates a Python 3.12 venv and installs ".[dev]"
make migrate          # alembic upgrade head  (requires PostgreSQL)
make dev              # uvicorn on 0.0.0.0:8000
```

Environment is loaded from `.env` (see `.env.example` at the repo root).

## Endpoints

| Method | Path                    | Description                        |
|--------|-------------------------|------------------------------------|
| GET    | `/health`               | Basic liveness + service metadata  |
| GET    | `/health/live`          | Process liveness                   |
| GET    | `/health/ready`         | DB + Redis readiness               |
| GET    | `/health/detailed`      | Per-dependency health report       |
| GET    | `/`                     | Service info with links            |

Every `/health*` route is also available under the `/api/v1` prefix.

## Layout

```
apps/api/
├── app/
│   ├── api/                # HTTP routes (health router)
│   ├── core/               # config, database, redis, logging, security
│   └── main.py             # FastAPI application + lifespan wiring
├── alembic/                # migration environment + versions
├── tests/                  # pytest suite
├── pyproject.toml          # packaging, ruff, mypy, pytest config
└── Makefile                # developer / CI commands
```

## Commands

```bash
make test          # pytest
make lint          # ruff check
make format        # ruff format
make format-check  # verify formatting
make typecheck     # mypy (app only)
make migrate       # alembic upgrade head
make revision m="..."   # new autogenerated migration
make offline-migrate    # validate migrations without a DB (--sql)
```
